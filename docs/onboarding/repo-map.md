# Repository Map

## Overview

This repository is a single-package, private npm application named `preishare-org-repo`. It is a blank TanStack Start scaffold using React 19, TypeScript, Vite, Tailwind CSS v4, and TanStack Router file-based routes. The application lives at the repository root; it is not a monorepo or workspace.

The local clone belongs to the learner's fork. The verified remote setup recorded in [setup-log.md](setup-log.md) uses the learner's fork as `origin` and the team repository as `upstream`.

| Path | Purpose |

## Frontend

The frontend is a TanStack Start React app rooted in `src/`.

| Path | Purpose |
| --- | --- |
| `src/routes/__root.tsx` | Root document shell: page metadata, global stylesheet, header, footer, devtools, and rendered route children. |
| `src/routes/index.tsx` | File-based `/` route and current home-page React component. |
| `src/routes/about.tsx` | File-based `/about` route and its page component. |
| `src/components/` | Reusable visual React components: `Header.tsx`, `Footer.tsx`, and `ThemeToggle.tsx`. |
| `src/styles.css` | Global CSS, Tailwind entry, font setup, theme tokens, and shared visual styles. |
| `src/router.tsx` | Creates and registers the TanStack Router instance. |
| `src/lib/user.ts` | Small shared TypeScript user-profile placeholder used for UI-facing application logic. |

## Backend and Data

No data layer is currently implemented.

- No Supabase client or configuration file exists. `.cursorrules` refers to an expected `src/lib/supabase.ts`, but that path is not present.
- No PostgreSQL configuration, SQL files, migrations, migration folder, or database tooling is present.
- No `.env.example` or other committed environment template is present. `.env` is ignored by `.gitignore`, and `AGENTS.md` states that this blank scaffold currently needs no environment variables.
- No implemented server functions or API routes were found. TanStack Start supports these capabilities, but the references in `README.md` are starter documentation rather than application code.

When backend functionality is introduced, `src/lib/` is the likely location for shared data helpers and `src/routes/` is the likely location for route-owned server functions or API routes. This describes the current project structure only; it is not guidance for changing production data.

- `docs/onboarding/` for onboarding documentation.

## Do Not Edit Yet

- `src/routeTree.gen.ts` is generated by TanStack Router and is explicitly marked not to edit by hand.
- `package-lock.json` should change only through intentional dependency operations.
- `tsconfig.json`, `tsr.config.json`, and `vite.config.ts` are shared toolchain configuration; change them only when a task requires it.
- `.vscode/settings.json`, `AGENTS.md`, and `.cursorrules` are editor/agent configuration and project guidance, not ordinary feature code.
- `.env` files are local configuration and ignored by Git; no secret values belong in committed source files.
