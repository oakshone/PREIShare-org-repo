When adding a new contributor, keep the existing entries intact and add one row using the same columns and format. Avoid expanding the scope into generated route files, lockfiles, toolchain config, or other protected files without an explicit task assignment.

## First contribution guidance

- Prefer small, reviewable PRs in onboarding docs or a minimal UI copy update.
- Keep the app at the repo root; this is not a monorepo workflow.
- Do not edit generated route files, lockfiles, or shared toolchain config unless the task clearly requires it.
- Do not add local secrets or environment values to committed files.
